# WORKFLOW.md

## Как работать с этим проектом через Codex

### Базовый принцип
Не делать полную пересборку сайта без необходимости.
Сначала аудит, потом план, потом внедрение по этапам.

### Порядок работы
1. Изучить AGENTS.md и docs/*
2. Проверить текущее состояние файлов
3. Сформулировать краткий план этапа
4. Внести изменения только в рамках этапа
5. Показать diff и краткое summary
6. Обновить STATUS.md

### Что делать в первую очередь
1. Hero-блок
2. Блок болей клиентов
3. Блок "что входит во внешний IT-отдел"
4. Блок "как мы работаем"
5. Тарифы
6. CTA и форма
7. Мобильная версия

### Что не делать без отдельного решения
- полный rewrite проекта
- замену всех assets
- радикальную смену визуального стиля
- внедрение сложных библиотек и зависимостей
- выдуманные маркетинговые обещания

### Формат ответа Codex на нетривиальную задачу
Сначала:
- что понял
- что проверил
- какие проблемы нашёл
- какой предлагает план

Потом:
- изменения в коде
- список файлов
- краткий итог

### Обязательные проверки после правок
- структура секций не сломана
- CTA на месте
- тексты соответствуют позиционированию
- мобильная версия не теряет навигацию
- форма не сломана
- diff чистый и понятный
