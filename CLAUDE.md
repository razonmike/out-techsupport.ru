# CLAUDE.md — TechSupport Website Project

## Контекст проекта

TechSupport — IT-аутсорсинговая компания из Казани.
Основное позиционирование: **внешний IT-отдел для бизнеса.**
Главная цель сайта: получать заявки на **абонентское IT-обслуживание**.

Подробный контекст — в `AGENTS.md`, `docs/PROJECT.md`, `docs/SITE_PLAN.md`.

## Следующие этапы рефакторинга (очерёдность согласована)

### Этап 2 — Блок болей клиентов (новая секция)
Добавить новую секцию **сразу после `<section class="hero">`**, до секции `#services`.

Название секции: `«С какими задачами обращаются»`
Формат: сетка карточек (4 колонки на десктопе, 2 на планшете, 1 на мобайл)

Карточки (8 штук):
1. Нестабильный интернет и Wi-Fi
2. Сбои и зависания рабочих мест
3. Проблемы с 1С
4. Не работает принтер или МФУ
5. Нет нормального VPN для удалёнщиков
6. Слабая или неструктурированная локальная сеть
7. Нет резервного копирования данных
8. Нужен постоянный IT-подрядчик

Правила текста для карточек:
- Заголовок карточки = боль клиента, не название услуги
- Подзаголовок (1 строка) = коротко, чем это мешает бизнесу
- Без технических терминов

Правила CSS:
- Не добавлять новые CSS-переменные без необходимости
- Переиспользовать `.card`, `.cards`, `.section-with-bg`, `.reveal`
- Добавить класс `.cards-4` для 4-колоночной сетки, по аналогии с `.cards-3`

## Правила работы с этим проектом

**Не делать без явного запроса:**
- Полный rewrite проекта
- Замену assets
- Смену визуального стиля
- Внедрение npm-зависимостей

**Всегда:**
- Работать поэтапно, один блок за раз
- Сначала описывать план, потом вносить изменения
- Держать diff чистым
- Проверять, что CTA и форма на месте
- Писать на русском языке, деловым стилем

**Запрещённые формулировки:**
- «под ключ»
- «индивидуальный подход»
- «команда профессионалов»
- «динамично развивающаяся компания»
- «мы не просто чиним компьютеры»
- любые неподтверждённые обещания с цифрами

**Предпочтительные формулировки:**
- «внешний IT-отдел»
- «абонентское IT-обслуживание»
- «удалённо и с выездом»
- «поддержка пользователей, сети, 1С, VPN, серверов и резервного копирования»
